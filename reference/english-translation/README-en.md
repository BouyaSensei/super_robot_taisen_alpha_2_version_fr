# 2nd Super Robot Taisen Alpha - English Translation

## About

*Language disclaimer: My native language is Spanish. I can read English without any problem, but I struggle with writing and speaking it, so some of the manual fixes in this project may contain imperfect English.*

This is a personal project aiming to translate the PS2 game 2nd Super Robot Taisen Alpha into English.


## Limitations

**Byte limit.** Because the English text is subject to a very strict byte limit, some compromises were necessary:

1. Repeated punctuation (`!!`, `??`, `...`) is trimmed to a single character (`!`, `?`, `..`) to save space.
2. Some terms are abbreviated where space is tight — for example: Federation → Fed, Organization → Org, Neo Zeon → NZeon, Photon Power Lab → Photon(ic) Lab.
3. In the most extreme cases, if a line still doesn't fit after all other measures, names may be shortened further or removed entirely, depending on context. For example, "Quattro" may appear as Quatro, Qttr, or even just Q. (This case is just an example, he appear in this game as Char)
